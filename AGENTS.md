# Context7 MCP Usage Guideline

Ketika mencari dokumentasi library, framework (seperti Laravel, Vue, React, dll.), SDK, API, konfigurasi, atau CLI tools:
- **Selalu gunakan Context7 MCP** (`resolve-library-id` dan `query-docs`) terlebih dahulu sebelum menggunakan web search.
- Ikuti alur Context7:
  1. `resolve-library-id` dengan nama library dan topik yang dicari.
  2. `query-docs` menggunakan library ID yang diperoleh untuk mengambil dokumentasi resmi dan up-to-date.
